Step one of the password recovery: ask for the identifier. Level 2 rather than core's bare h3. A plugin cannot know how deep in the outline it sits, but it does sit inside a content element whose own header is usually an h2, and an h3 under a hidden element header leaves a gap in the outline. Integrators re-level by overriding this one template.
false rather than an empty string: Fluid's tag builder drops an attribute whose value is false and renders aria-describedby="" for an empty one, which points a screen reader at nothing.
