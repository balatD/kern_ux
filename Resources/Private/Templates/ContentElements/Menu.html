Rendering shell for the core menu content elements. One template for all four: the HMENU that differs per element is configured as the numbered child 20 of its own tt_content object, exactly as lib.contentElement does for plugins, so f:cObject on tt_content..20 reaches whichever one is being rendered. The list markup itself comes from lib.kernUx.menuLevels and is the same kern-list the sitemap block emits. The nav landmark is named after the element heading. A page can hold several menus, and unnamed nav landmarks are indistinguishable to anyone navigating by landmark (WCAG 1.3.1). header_layout = 100 hides the heading visually but the text is still the best name for the region, so the label does not depend on it.
