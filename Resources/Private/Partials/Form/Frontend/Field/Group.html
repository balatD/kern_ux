The grouped variant: checkbox and radio groups are a kern-fieldset, not a kern-form-input. aria-describedby sits on the fieldset, but every child input additionally needs aria-invalid and the error class - KERN is explicit about this, and missing it leaves the group with a red bar while the individual controls look untouched, which fails WCAG 1.4.1. aria-required sits on the fieldset too, and only there. A fieldset maps to role="group", which supports the attribute, and the legend is what carries the group's accessible name. Repeating it on every option would say that each option is required by itself - true for neither a radio group nor a checkbox group that asks for at least one choice. Without this the inverted optional marker is the only signal that a group is required, i.e. a visual one only (WCAG 4.1.2).
