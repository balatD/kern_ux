The single checkbox uses KERN's other wrapper family: kern-form-check, with the input BEFORE the label - the opposite order to kern-form-input. Field/Field is therefore only used for the error and hint plumbing, with its own label suppressed. No optional marker here: a single consent checkbox is either required or it is not, and marking it "optional" reads as if ticking it were pointless.
