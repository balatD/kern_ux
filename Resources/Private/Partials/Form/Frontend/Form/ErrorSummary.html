KERN requires an error summary but ships no component for it - its own docs list WCAG 4.1.3 ("error summary marked up as a status message") as implementation-dependent. So this is assembled from KERN's alert. role="alert" is correct *here*, unlike on a content alert: this markup only exists after a failed submit, so there genuinely is something new to announce. Each entry links to the field it belongs to, which is what turns the summary from a list of complaints into a way of fixing them.
