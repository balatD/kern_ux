Page chrome shared by every backend layout. The page templates only arrange content inside
, which keeps landmark structure and heading order in one place instead of repeated per layout. The chrome is wrapped in f:spaceless, but
deliberately is not: spaceless collapses whitespace between tags, and editorial content relies on the space between inline elements ("a b"). The Kopfzeile belongs to the Digitale Dachmarke and is reserved for federal, state and municipal offerings, so it stays off unless a site opts in explicitly. Both resolved up front: f:uri.resource does not degrade gracefully on an empty path, and a header with neither logo nor title would render an empty link. A one-item breadcrumb is just the current page and carries no information, so it is suppressed rather than rendered as a dead end.
