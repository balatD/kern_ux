Bridges the core header fields to the heading component. Level and visual size stay separate all the way through: KERN requires it so a block can sit at any depth of the document outline without changing its look, and header_layout = 100 is core's "hide this heading", which has to mean *no element* rather than a visually hidden one. An empty appearance means "use the default". Guarded here rather than in every block: the blocks pass the raw database value through, and an empty one would otherwise render the invalid class "kern-heading-". One line: the heading text is a text node, so any line break around it survives f:spaceless and shows up inside the heading. {header}{header}
