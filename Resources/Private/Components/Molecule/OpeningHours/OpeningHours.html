KERN has no opening-hours component, but it needs none: this is its description list, and every class here is KERN's own. It exists as a component rather than as markup in the content block because molecule.descriptionList takes its values as strings and escapes them, so a element cannot pass through it - and the machine-readable time is the whole point of the pattern. Deliberately without kern-description-list--col. The modifier reads as if it made columns; it does the opposite. The base item is flex-direction: column and turns into a 30/70 row at 768px, while --col forces both halves back to width: 100% and so keeps them stacked. Day beside hours is the reading a table of opening times needs, so the modifier stays off. No "Uhr" suffix. A range between two elements is unambiguous in every language, and a translated unit would put a stray space in the markup on the locales that do not use one.
