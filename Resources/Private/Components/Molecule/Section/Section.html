The wrapper every content block sits in. It exists because a block usually emits several sibling elements (a heading plus its body), and vertical spacing has to attach to something that encloses all of them. The base class is always there, and that is what carries the default vertical rhythm between blocks. Without it every element sat flush against the next, because core's "default" spacing value means "nothing" and that is what most blocks have - so the page had no rhythm at all unless an editor set one per block.
