KERN has no download list, so this is ours (kernt3-). Format and size belong in the link text, not in a separate column: a link has to be understandable from its text alone (WCAG 2.4.4), and "Merkblatt" tells a screen reader user nothing about what they are about to download. So does the accessibility note, and for the same reason. BITV 2.0 covers published documents, not only pages, and a PDF exported from a layout program is almost never accessible - so a visitor who needs one has to know before they open it, not after. It is plain text inside the link rather than a badge beside it: a badge is skipped by exactly the people it is for. Shown whenever the flag is not set, because the flag defaults to "not known to be accessible". A document that is accessible is marked as such by an editor; assuming it in the absence of any statement is the one failure mode worth avoiding, since it tells somebody a document is usable when nobody ever checked. Takes plain data rather than FAL objects, so the mapping lives in the content block and the component can be shown without editorial content.
