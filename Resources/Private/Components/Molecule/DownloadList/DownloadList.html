KERN has no download list, so this is ours (kernt3-). Format and size belong in the link text, not in a separate column: a link has to be understandable from its text alone (WCAG 2.4.4), and "Merkblatt" tells a screen reader user nothing about what they are about to download. Takes plain data rather than FAL objects, so the mapping lives in the content block and the component can be shown without editorial content.
