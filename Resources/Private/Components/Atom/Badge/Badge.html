The text goes in a kern-label span rather than straight into the badge: KERN styles badge text through `.kern-badge .kern-label`, so text placed directly in the badge inherits whatever the surrounding context happens to be - which is how our status badges ended up lighter and smaller than KERN's. No size class on the icon. KERN's own badge example writes `kern-icon--sm`, which 2.7.2 does not define at all (small | large | x-large); `.kern-badge .kern-icon` already fixes the box at 24px.
