Rendered only when there is something to show: an empty footer landmark is announced to screen reader users as a region with no content. KERN has no footer component, so this is ours (kernt3-), assembled from KERN utilities and tokens so it stays visually consistent.
kernt3-footer__inner is not decoration: KERN zeroes a kern-container's padding when it contains a kern-grid, and the link columns below are one - so without a class of our own to put the inline padding back, the footer sits flush against both edges of a phone screen. Same reason kernt3-content-area carries it.
