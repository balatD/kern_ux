KERN has no hero, so this is ours (kernt3-): the opening block of a service page or a start page, carrying the heading, a short lead, one note and a picture. The picture is never the message. It gets no caption and it is not a figure: a hero image illustrates, and anything a visitor actually needs is in the text beside it. An image with something to say belongs in the image or text-and-media block instead. Text comes before the image in the source whichever side it is shown on - the side is a grid order, so reading order follows the content and not the layout. The image loads eagerly: a hero is above the fold by definition, and lazy loading delays exactly the image the page is judged by. Resolved in steps rather than in one inline f:if: an inline f:if evaluates both branches before it picks one, and interpolating a file reference into a string is not something a FAL object survives.
