The GOV.UK-style task list KERN uses for application journeys. The heading carries the base kern-heading class in addition to its size class: KERN styles it through a descendant selector (.kern-task-list__header .kern-heading) that only matches the base class - KERN's own example omits it and therefore misses its own rule. A journey with several sections - "Persönliche Daten", then "Zusammenfassung" - is one organism.taskListGroup holding one of these per section. KERN's reference puts several header/list pairs inside a single kern-task-list instead; both produce the same 32px between sections (there from kern-task-list-group's gap, there from the second header's margin-top), and one list per heading is the better markup: each heading then labels a list of its own instead of one list carrying two headings.
